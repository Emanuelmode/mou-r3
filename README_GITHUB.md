# MOU Web

Paquete reconstruido para GitHub Pages a partir de los archivos MOU recuperados.

## Archivos
- `index.html` — portada principal MOU, con hipótesis, CWRU, ECG, EEG, métricas, embedding, controles y trazabilidad.
- `mou-lab.html` — laboratorio visual autónomo.
- `ecg-3d-viewer-R3-MOU-fixed.html` — visor ECG/R³.
- `eeg-three-scene.html` — visor EEG Observability.

## Publicación
Subir el contenido de esta carpeta a la raíz del repositorio de GitHub Pages. No requiere build. Los gráficos usan Plotly desde CDN y los visores 3D usan módulos Three.js desde CDN.

## Nota
La web conserva lenguaje exploratorio y límites de claim. Los visores ECG/EEG son visualizaciones de investigación, no herramientas diagnósticas.
